# Proposed System Architecture

| Component | Purpose |
|---|---|
| Soil-moisture sensor | Estimates how wet or dry the soil is near the plant roots. |
| Temperature / humidity sensor | Adds context about the surrounding environment. |
| Microcontroller | Reads sensors and applies the irrigation decision rule. |
| Connectivity module | Sends readings to a dashboard or gateway over a suitable network. |
| Relay and pump/valve | Switches the irrigation equipment on or off safely. |
| Dashboard | Displays measurements, alerts and recent activity. |
