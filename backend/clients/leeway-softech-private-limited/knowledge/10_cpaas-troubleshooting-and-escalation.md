# CPaaS Troubleshooting and Escalation

Unsent Messages: Check server credentials, service status, recipient number formatting (+country code), template approval, and provider API response.

Unclear Status: Query report API using Message ID. Do not claim "delivered" unless API explicit status confirms it.

Escalation Triggers: Escalate outages, billing issues, account lockouts, template rejections, or compliance queries to support (+91 8000305305). Collect minimum reference details only.
